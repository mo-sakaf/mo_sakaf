Welcome to the repository of my personal portfolio website! This project serves as a digital resume and a showcase of my creative journey, projects, and skills.

## 🚀 About The Project (عن المشروع)
This is a modern, fully responsive personal portfolio designed with a sleek **Glassmorphism (iOS-style)** aesthetic. It highlights my expertise across multiple fields including:
- **UI/UX Design** 🎨
- **Front-End Development** 💻
- **Video Editing & Montage** 🎬
- **Singing & Music** 🎤

🔗 **Live Website:** [mo-sakaf.github.io/mo_sakaf](https://mo-sakaf.github.io/mo_sakaf/)

## 🌟 Key Features (أهم المميزات)
- **Bilingual Support (AR / EN):** Seamlessly switch between Arabic and English without reloading the page.
- **Glassmorphism UI:** Premium frosted-glass effects applied to buttons, cards, and navigation.
- **Dynamic Filtering:** Interactive tabs to filter through my diverse portfolio categories.
- **Responsive Design:** Optimized for all devices (Desktops, Tablets, and Mobile phones).
- **Custom Animations:** Smooth scrolling, typing effects, and hover transitions.

## 🛠️ Built With (التقنيات المستخدمة)
- HTML5
- CSS3 (Custom Variables, Flexbox, CSS Grid)
- Vanilla JavaScript

## 📂 Repository Structure (هيكل المشروع)
- `/assets`: Contains all images, icons, and media files.
- `/css`: Stylesheets including `style.css` for main styles and `responsive.css` for media queries.
- `/js`: JavaScript logic (`main.js`, `language.js`, `portfolio.js`, `animation.js`).
- `index.html`: The main entry point of the application.
